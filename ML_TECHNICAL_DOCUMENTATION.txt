#### 3.2.3 TF-IDF Vectorization
**Method:** Term Frequency-Inverse Document Frequency

**TF-IDF Formula:**
\\\
TF-IDF(t, d) = TF(t, d) × IDF(t)

Where:
TF(t, d) = (Number of times term t appears in document d) / (Total terms in document d)
IDF(t) = log(Total documents / Documents containing term t)
\\\

**Implementation:**
\\\python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer(
    max_features=5000,      # Keep top 5000 features
    min_df=2,               # Minimum document frequency
    max_df=0.8,             # Maximum document frequency
    ngram_range=(1, 2),     # Unigrams and bigrams
    stop_words='english',   # Remove English stop words
    sublinear_tf=True,      # Use log scaling for TF
    lowercase=True,         # Convert to lowercase
    norm='l2'               # L2 normalization
)

X_tfidf = vectorizer.fit_transform(X_train)
\\\

**Parameters Explained:**

1. **max_features=5000**
   - Keeps only top 5000 most important features
   - Reduces dimensionality from 42,189 to 5,000
   - Balances between information and efficiency

2. **min_df=2**
   - Ignores terms appearing in <2 documents
   - Removes rare/noisy terms
   - Filtered out 28,934 rare terms

3. **max_df=0.8**
   - Ignores terms appearing in >80% of documents
   - Removes overly common terms
   - Filtered out 156 very common terms

4. **ngram_range=(1, 2)**
   - Unigrams: Single words (e.g., "python")
   - Bigrams: Two-word phrases (e.g., "machine learning")
   - Captures contextual information

5. **sublinear_tf=True**
   - Applies log scaling: 1 + log(tf)
   - Reduces impact of very frequent terms
   - Improves model stability

6. **norm='l2'**
   - Normalizes feature vectors to unit length
   - Ensures documents of different lengths are comparable

### 3.4 Normalization, Resizing, and Rescaling

**Objective:** Standardize feature scales for optimal model performance.

#### 3.4.1 TF-IDF L2 Normalization
**Method:** L2 norm (Euclidean normalization)

**Formula:**
\\\
normalized_vector = vector / ||vector||₂

Where ||vector||₂ = sqrt(sum(x²) for x in vector)
\\\

**Implementation:**
\\\python
vectorizer = TfidfVectorizer(
    norm='l2',  # L2 normalization
    # ... other parameters
)

# Each document vector has L2 norm = 1
X_normalized = vectorizer.fit_transform(X_train)

# Verify normalization
from sklearn.preprocessing import normalize
norms = np.sqrt((X_normalized.multiply(X_normalized)).sum(axis=1))
print("All norms = 1.0:", np.allclose(norms, 1.0))
# Output: True
\\\

**Why L2 Normalization:**
- Makes documents of different lengths comparable
- Prevents longer documents from dominating
- Required for cosine similarity
- Improves model convergence

#### 3.5.2 Cross-Validation Strategy

)

    model,
