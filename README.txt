RESUME AI STUDIO - kaise chalayein (Windows)

1. Is folder me apni Resume_csv.xls file copy karo (app.py ke bagal me).
2. PowerShell is folder me kholo aur:
      pip install -r requirements.txt
3. App chalao:
      python app.py
4. Browser me kholo:  http://127.0.0.1:8000
5. Dashboard tab -> "Train model" dabao (1-2 minute). Phir Classify / Generate tabs use karo.

Generative AI (optional): Settings tab me Gemini API key daalo
(free key: https://aistudio.google.com/app/apikey). Bina key ke template mode chalta hai.
